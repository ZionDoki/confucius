# Confucius Chrome extension

1. Install the Confucius Zotero addon and copy the pairing token from Confucius prefs.
2. Chrome → `chrome://extensions` → Load unpacked → this directory.
3. Open the side panel, paste the token, click Pair.
4. On arXiv / PubMed / DOI pages, click **This tab** to push identifiers into the current session.
