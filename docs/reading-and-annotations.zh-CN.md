# 报告与批注

[English](reading-and-annotations.md) · 简体中文

[使用指南](README.zh-CN.md)

## 阅读或比较论文

通过 `@`、Zotero 条目入口或确认文献候选添加来源。
输入 `/` 查看适用于当前来源的预设。选择预设只准备当前对话的草稿，发送后才开始。

**论文阅读**可在生成前选择排版、文风和阅读侧重点。
默认是“分节讲义＋耐心讲解＋全文脉络”。修改风格作用于下一次生成或改稿，
不会自动重写已有报告；不明白的段落可以继续追问。

## 输出语言

回答、生成的进度说明、批注评论、报告标题及修订优先遵从明确指定的语言，其次跟随
当前请求的语言，再继承最近有效对话语言；界面语言只作回退。纯技能命令和继续执行
继承对话语言。原文引文和批注定位信息保持原文。

## 打开与修改报告

点击对话中生成的文件，报告会在工作区打开，左上角箭头返回任务。
使用**独立窗口**可与 PDF 并排阅读。

点击来源链接可回到 Zotero 条目、PDF 页或批注。在同一对话中提出具体修改，
例如“核对这个数字，并同步修改开头摘要”。改稿沿用同一报告并保留历史版本。
版本菜单可固定旧版本；选择**最新版**后恢复跟随更新。

“就绪”表示报告可交付，不代表事实已经认证。精读报告可利用当前模型和剩余额度
做一次自动修订；修订失败时，已保存报告仍可使用。

## 保存与导出

生成报告会保存任务成果，不会立即写入 Zotero 笔记。

1. 在报告中点击 **Zotero 笔记**。
2. 查看排版预览。
3. 确认写入；之后保存会更新关联的同一笔记。

知识库会索引该笔记，无需另选知识库或填写 ID。
**导出文件**可生成独立 HTML 副本，具体行为见[知识库与记忆](knowledge.zh-CN.md)。

## 审阅 PDF 批注建议

可以直接要求高亮或评论，并指定页码和数量。

下文的自动展开、后续提醒和默认视图行为从 0.6.1-beta.1 起生效。

1. Agent 首次提交批注时自动展开审阅区；之后可点击输入框上方的**批注**胶囊重新打开。
2. 在卡片或列表中检查原文、评论和页码；少于 10 项默认卡片，从 10 项起默认列表，
   可手动切换。
3. **接受**后才写入 Zotero；**拒绝**不会写入，可以撤销。
   需要批量处理时，可先搜索或筛选。
4. 点击页码核对原文。

普通工具授权不会自动接受 Agent 批注建议。只有取得实际写入回执才显示已保存。
结果不确定时使用**核对写入状态**，不要直接重复写入。

最小化后保留勾选和阅读位置；后续新建议更新数量，并在胶囊上播放短暂提醒动画，
不强制打开浮层。减少动态效果设置下只提示新增数量。历史记录默认收起，
已保存的处理结果在重启后仍保留。

## 在 PDF 阅读器中阅读评论

从 0.6.3 起，原生 PDF 批注卡片和评论弹窗跟随 Confucius 的
[外观设置](appearance.zh-CN.md)，包括字体、字号、行距和深浅配色。
保存设置后，已经打开的阅读器也会更新。
在**外观 → PDF 批注**中选择**单独设置批注**，即可调整批注字号、行距和段落间距，
不影响聊天与报告。

评论支持 Markdown 标题、列表、表格、链接和围栏代码，以及行内 `$...$`
和独立 `$$...$$` 公式。点击**编辑评论**使用 Zotero 原生编辑器，
点击编辑器外部返回排版预览；Escape 沿用 Zotero 原生的焦点和弹窗关闭行为。
空评论仍可直接输入，只读批注保持只读。
长评论在弹窗内部滚动。
拖动弹窗任意一个角可以调整大小，始终限制在阅读分栏内；阅读器保持打开期间会记住
所选大小。双击任意角恢复自动大小。键盘聚焦角标后可以用方向键微调，按住 Shift
扩大步幅，回车恢复默认；Escape 沿用 Zotero 原生弹窗关闭行为。

排版不会改写保存的评论、批注颜色或标签。Flex Annotations 的定位标签、
编辑菜单与 `§章节标题` 归类继续使用原生入口。此预览作用于桌面界面，
其他客户端和导出的 PDF 使用各自的排版。停用 Confucius 后恢复原生显示。

## 批次与已有批注

新批注不再自动添加 Confucius 标签。已有的 Confucius 标签和用户标签保持原样，
重启也不会改写；不需要的旧标签可在 Zotero 中手动移除。对话批次及时间仍在内部记录，
Agent 每次提交的建议仍是独立审阅批次。可用 Zotero 自带搜索和标签筛选；
旧的自定义 PDF 批次筛选器已移除。

Agent 可按权限和审阅流程修改、删除有 Confucius 归属记录的批注，
不能凭标签或颜色冒充归属。添加来源时会保留 PDF 已有颜色，
因此新增批注的实际颜色可能与请求不同。

## 用 Flex Annotations 整理已有标注

此集成从 0.6.3-beta.2 起提供。先在
[Flex Annotations](https://github.com/justanotherjurastudent/zotero_FlexAnnotate)
中建立大纲，再让 Confucius 整理指定分类中尚未归类的标注。子分类使用其顶层分类的大纲，
处理范围也包含该顶层分类及其子分类；若没有大纲，请先创建。

将工具权限设为**询问**时，审核卡片按章节分组，展示引文和来源。
逐条点击**接受**或**拒绝**决定保留哪些提案，再点击**应用**提交已接受的条目。
可以按文字、接受或拒绝状态筛选，时间线刷新会保留选择。
明确要求预览的操作，即使批准也不会写入标签。
**本次会话记住**会授权当前任务后续对该工具的调用；只批准本批时，请使用应用按钮。

接受归类后，已有标注会增加大纲对应的 `§章节标题` 标签。
只有明确要求取消归类时才会删除这些标签，其他标签和大纲笔记保持不变。
取消归类仅限所选分类范围内的标注和该分类大纲中的章节。
Confucius 不创建、重命名或删除大纲章节；不可编辑的标注会跳过。

Flex Annotations 未加载时，Confucius 仍可读取已保存的大纲。
建立或修改大纲请使用 Flex Annotations。此流程用于整理已有标注，
新增 PDF 高亮请使用上文的标注审核流程。
