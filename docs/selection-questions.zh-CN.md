## 阅读时直接提问

在 PDF、报告或对话中选中文字，在选区附近输入问题并按 **Enter**。
回答会在原处显示，也可以继续追问。中文输入法确认候选时的 Enter 不会发送。

点击外部或按 **Escape** 返回阅读。关闭浮层不会停止回答；
再次选中文字可以打开已保存的旁支对话。

## 能参考哪些上下文？

| 选区位置 | 可用材料                                         |
| -------- | ------------------------------------------------ |
| PDF      | 选中文字、该论文，以及关联任务中已完成的相关对话 |
| 报告     | 所选报告版本及其任务的已完成历史                 |
| 对话     | 该任务的已完成历史                               |

PDF 旁支按文库中的论文归属，独立附件单独区分。
同一任务的报告和对话共用旁支；每次发送固定当时的选区、来源和版本。

这个模式只读：不联网搜索，不读取全局记忆或其他旁支，
不修改笔记、批注和报告，也不把内容加入主任务或自动记忆提取。

## 模型与保存

任务旁支首次创建时继承任务的运行方式和外部模型设置。
PDF 旁支使用最近更新的关联任务运行方式，没有关联任务时使用 Native。
旁支使用自己的模型会话。

旁支保存在运行数据目录的 `btw/` 下。
重启会中断未完成回答，保留已保存内容，不自动重发。
删除任务会删除其任务旁支；删除或将论文移入回收站会清理对应 PDF 旁支。

旁支也受历史自动清理规则约束，详见[上下文与历史](context-system.zh-CN.md)。
扫描 PDF 需要先在 Zotero 中获得可选文字，才会出现划线入口。
