## 安装更新

1. 打开 **Confucius 设置 → 更新**，检查可用版本。
2. 核对版本后点击**下载并安装**。
3. 按界面提示操作：有些更新立即生效，暂存安装可能需要重启 Zotero。

Confucius 自行比较版本和校验安装包。
Zotero 的全局自动更新开关不会禁止 Confucius 手动检查。

## 稳定版还是 Beta？

| 设置                 | 接收版本                        |
| -------------------- | ------------------------------- |
| 关闭“接收测试版更新” | 只接收稳定版                    |
| 开启“接收测试版更新” | 比较稳定版和 Beta，提供更高版本 |

关闭 Beta 不会降级已安装版本。
同一基础版号的正式版高于 Beta，明确选择的渠道会在重启和升级后保留。

**自动检查更新**是独立开关：开启后，启动约 30 秒检查一次，之后每六小时检查。
安装仍需点击按钮。

## 更新失败时

| 问题                                        | 处理方法                                                         |
| ------------------------------------------- | ---------------------------------------------------------------- |
| 网络或限流错误                              | 稍后重试。                                                       |
| “has no Confucius installation package yet” | 发布信息暂缺可用 XPI，稍后重试，无需卸载。                       |
| 校验失败                                    | 保留当前安装，重新获取有效安装包。                               |
| 界面版本似乎没变                            | 关闭并重新打开整个 Confucius 工作区；仍提示需要时再重启 Zotero。 |

不具备此更新器的旧版，可以通过 Zotero 插件管理器安装 XPI。
详见[安装步骤](../README.zh-CN.md#安装)。

## 文档与已安装版本的区别

仓库指南对应当前代码，尚未发布的能力可能先出现在文档中。
请核对设置中显示的版本；历史变化以[发布记录（英文原文）](../CHANGELOG.md)为准。

更换版本前先[备份数据](tasks-and-data.zh-CN.md)。
构建或安装成功，不等于所有迁移与平台场景都已经实测。
