# 外观设置

[English](appearance.md) · 简体中文

[使用指南](README.zh-CN.md) · [CLI 连接](runtime-discovery.zh-CN.md)

打开 **Confucius 设置 → 外观**，或 **Zotero 设置 → Confucius → 外观**。
设置使用顶部标签。修改后点击**保存**，即可更新已打开的 Confucius 工作区、阅读窗口
与划线询问弹窗。关闭或取消会丢弃未保存的外观修改。
从 0.6.3 起，这些设置也会应用到原生 PDF 批注卡片和评论弹窗，
详见[阅读批注评论](reading-and-annotations.zh-CN.md#在-pdf-阅读器中阅读评论)。
保存提交期间暂时不能编辑或取消，提交成功或出错后恢复操作。

- **字号**：12–28 px，步进 0.5 px，可使用滑块或输入数值。
- **行距**：1.2–2.4，步进 0.05，用于阅读正文。
- **PDF 批注**：默认跟随全局设置。选择**单独设置批注**后，可以分别调整
  批注字号（12–28 px）、行距（1.2–2.4）和段落间距（0–32 px）。作用于原生批注
  卡片和评论弹窗，不影响聊天和报告；字体与配色仍跟随全局外观。切回**跟随全局设置**
  并保存后，恢复全局排版与默认的 12 px 段落间距。
- **字体**：八种离线预设，或在**本机字体**中搜索并选择已安装字体。预设优先使用本机
  可用字体，缺失时使用系统字体，不会下载字体。在另一台电脑上缺少已保存字体时，
  暂时回退到系统字体，直到你重新选择。
- **主题**：跟随 Zotero、浅色或深色。配色编辑区的深浅色标签只选择要编辑的配色，
  不会切换当前主题。
- **配色**：选择默认暖色、中性配色，或自定义页面背景、工作区背景、控件背景、
  正文、次要文字与强调色。可输入 `#RRGGBB` 或使用颜色选择器。深浅色配色独立保存。

外观设置没有预览。**恢复外观默认值**只修改当前草稿，点击**保存**后生效。
默认值仍为 13 px、1.6 倍行距、系统无衬线字体与暖色配色；升级时保留旧版本已保存的
字体与行距档位。

系统高对比度优先于自定义颜色。修改仅作用于 Confucius 界面；Zotero 文献库、PDF
页面和其他设置页面使用各自的外观。
