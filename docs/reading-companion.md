# 精读陪读与研究报告

陪读功能从 0.4.5 起提供；旧安装包可能仍只有报告视图。

在精读任务中挂载一篇论文并发送阅读要求。Confucius 先阅读论文与已有批注，保存
精选原生高亮和简短评论，再生成陪读草稿。回查原文和实际批注后，陪读即可交付。
PDF 批注继续使用已有的预览与授权流程。

## 跟着文章读

从原来的成果入口打开，新陪读默认铺满插件主界面并显示“陪读”。左上角箭头返回
任务；点击“独立窗口”可与 Zotero PDF 并排摆放，当前视图、阅读位置和输入草稿
会随之保留。陪读沿论文的顺序连续排版：浅色块用一两句话交代这部分在做什么，重点
原文下方紧接相应的拆解。点击原文节选可回到 PDF 的对应位置。

总结块使用插件主题的浅色圆角样式，悬停时会变色并轻轻浮起，右上角标出起始页。
PDF 当前阅读部分的总结块会持续“点亮”：暖色底、柔和光晕和“正在读”标记，鼠标
移开后仍然保留。同一部分内翻页保持亮光，进入下一部分才转移；联动时总结固定在
正文上方独立占位，不遮住节选和来源链接。手动滚动陪读可以自由查看其他部分。
点击总结块可打开这一部分的起始页。陪读打开后，滚动同一篇 Zotero PDF 会带动陪读到
相应段落，不抢走 PDF 的焦点；双击 PDF 页面会切回对应陪读块。按物理页码匹配，
同页有多处时保留当前一处，否则选择该页按原文顺序的第一处。联动不改变正在
输入的追问或引用；其他论文不参与联动。

解释保留概念、步骤、证据与必要条件。需要时展开“作者怎么写的”，查看句段的
实际作用与前后承接；“展开这一步”补充小例子或中间步骤。原文节选保留原语言，
解释应区分作者陈述、已有证据与解释性推断。原文仍是核对事实的依据。

窗口在本地保存阅读位置、展开状态、引用和输入草稿，不增加成果版本。后台修订
保留仍存在的段落及阅读位置。“批注与未完成项”集中显示实际保存结果与来源链接；
对应批注被删除后，定位沿用 PDF 页码回退。

## 划选并追问

划选一段原文或解释，点击浮出的“引用”，所选内容会进入底部的统一输入框。
也可以先点击正在读的段落，再直接输入问题。Enter 发送，Shift+Enter 换行。
回答用气泡显示在输入框上方，点击收起按钮继续阅读；聚焦输入框可重新查看这段的
问答。引用和未发出的草稿会保留，滚动文章不会偷偷切换正在追问的内容。

第一次发送时为引用所在段落创建独立阅读分支，之后保留这段自己的问答。统一的
输入框只是入口；其他段落的问答不会自动带入。分支不复制主任务聊天或工具历史，
也不会进入普通任务列表、全局历史检索、记忆提取或后续研究报告。

分支只能读取这篇论文与自己的历史，不能修改正式成果、PDF 批注、记忆或知识库。
需要修订陪读时，回到主任务明确提出修改要求。首版没有自动合并或“采纳回答”。

“停止”只停止当前分支。切换 checkpoint 或关闭成果窗口不会停止后台回答，也不会
把回答显示到其他位置。重启后，未完成回答显示为中断，由你点击“继续回答”。
模型的上下文和执行额度独立；首次创建分支时使用主任务当前的模型配置。

当 checkpoint 或相关来源被修订，旧问答仍保留并显示所依据的版本，新问题进入
新版分支。只补充研究报告不会重置问答。删除所属主任务时，本地阅读分支与阅读
状态也会清理；外部模型服务商或 CLI 自有日志遵循各自的保留设置。

## 按需生成报告与保存笔记

切到“研究报告”，点击“生成研究报告”。报告由成果所属主任务基于已有成果和原论文
生成，包含一分钟概览、方法、关键证据表与边界，减少陪读中的逐段重复解释。
重复点击不会另起任务；主任务正在运行或等待审批时，需要等它结束后再生成。

报告草稿经过复核后保存到同一成果。失败或中断时，已有陪读继续可读；可以从报告
视图继续生成，或在主任务中点击继续。预览中的草稿不等于已经完成证据复核。

点击“保存 Zotero 笔记”，用顶部按钮选择“陪读”或“研究报告”，默认选中当前视图。
预览显示排版后的完整笔记；更新已有笔记时，可展开查看旧内容。点击“继续”核对，
再点击“确认保存”。标题、引用、表格、公式和原文链接会保留到笔记中，私人问答
不会保存。预览、确认和实际保存使用同一版本与同一视图；未生成的报告不能保存。
也可从“保存位置”选择研究知识库等已有目标。

旧报告与历史版本保持可读；升级或恢复旧任务不会自动补生成陪读。主界面和独立
窗口都可以与 Zotero PDF 联动，尚不提供 PDF 页边覆盖层。
