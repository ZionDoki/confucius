# 文献检索

[English](literature-research.md) · 简体中文

[使用指南](README.zh-CN.md)

## 找到第一批论文

可以这样问：“帮我找近几年用图神经网络预测分子性质的论文，推荐最相关的几篇并说明理由。”

1. 在新对话中提问，不必先添加论文。
2. 打开输入框上方的**文献**胶囊。
3. 查看摘要和筛选理由，在卡片中「纳入候选／排除」，或选中列表条目后批量操作。
4. 点击**确认候选 → 确认并获取全文**，把候选保存到个人 Zotero 文库，并尝试下载 PDF。

已有匹配条目和通过核验的附件会复用。更改候选后需再次确认；
移除候选只解除任务来源，不会删除 Zotero 条目或 PDF。

## 看懂数量与筛选

从 0.6.1-beta.1 起，候选与批注共用卡片和列表：少于 10 篇默认卡片，从 10 篇起默认列表，
可用两个视图按钮切换；后续检索保留你的选择。首次实时结果自动展开，
后续结果通过胶囊的短暂浮动提醒。本地搜索和状态菜单可查看未评估、
已纳入、已排除或全部论文。

“9 / 100”表示**实际获取并去重的 100 篇中，选了 9 篇候选**，不是搜索服务的总命中数。

**调整检索条件**会联网，**筛选当前结果**只查本地结果池。
OpenAlex 普通检索每页最多获取 100 条，语义检索最多 50 条；缺少摘要时，可从本地
Zotero、OpenAlex 和 Crossref 补查。

## Agent 短名单

以下行为已加入开发分支，尚未发布。

用户审阅界面保留完整结果池，Agent 默认只接收当前查询相关性最高的 10 篇，
最多 12 篇。排序以相关性为主、标准化影响力为辅；发表年份、场所和原始引用数
不直接代表论文质量。

默认排除已知撤稿和 paratext。只有存在具体证据缺口时，Agent 才通过 metadata
视图扩展候选，而不是读取整个结果池。可选的 OpenAlex rerank 会消耗更多请求额度。

## 发表场所评级

从 0.6.1-beta.2 起，卡片和列表会自动匹配 **CCF 2026 第七版**及 **CORE / ICORE2026**。
每项评级显示目录年份和来源链接；展开“评级详情”可查看学科分类及固定版本的数据快照。
这里的年份指评级版本，并非论文发表年份。

在文献审阅中打开“评级目录 → 导入 ShowJCR CSV”，或进入
“设置 → 运行时 → 发表场所评级”。选择来自
[ShowJCR](https://github.com/hitfyd/ShowJCR) 的 UTF-8 编码期刊 CSV，最大 32 MiB：

- `JCR2025-UTF8.csv`（也支持其他年份）：各学科 JCR 分区、影响因子和排名。
- `FQBJCR2025-UTF8.csv`：中科院大类、小类分区及 Top 标记。支持历史版本，
  不接受 2025 年之后的中科院目录。
- `XR2026-UTF8.csv`：新锐大类、小类分区及 Top 标记，单独显示为新锐，
  不标成中科院分区。暂不支持会议 CSV。

同体系、同年份的导入会替换该目录；各体系显示已导入的最新年份。
“移除”后可回退显示保留的较早版本。目录保存在本地 Zotero 配置中，重启后保留，
已有调研结果会自动刷新。导入不会添加标签、改动候选选择或改写文献库字段。
Confucius 不会替你下载这三类数据集。

匹配优先使用 ISSN，再使用确切名称或已识别的会议缩写。仓储、明确标为预印本的论文、
有歧义的名称和无法确认会议的论文集不会显示评级。会议等级适用于常规或长论文；
Findings、演示赛道和附属研讨会不会套用主会等级。独立列入目录的研讨会可匹配自己的条目。
“未匹配发表场所评级”不代表未评级，发表场所评级也不等同于单篇论文质量。

## 不必等所有 PDF 都齐全

| 选择           | 结果                                            |
| -------------- | ----------------------------------------------- |
| 仅用摘要继续   | 不为本批次入库或下载，先继续研究。              |
| 按当前结果继续 | 使用已有 PDF 和摘要，已授权的下载可在后台完成。 |
| 确认并获取全文 | 保存候选、绑定任务来源，并下载可用 PDF。        |

选择针对当前这批候选。报告应区分全文、仅摘要和仅元数据的证据；
“已获取 PDF”不等于“Agent 已读全文”。

## 可选的服务 Key

在**设置 → 运行时**中可以配置：

- **OpenAlex Key：**用于 OpenAlex 请求；缓存 PDF 需要 Key。
  插件允许不填 Key 发起元数据请求，服务方可能限流或拒绝。[获取 Key](https://openalex.org/settings/api)。
- **Tavily Key：**用于补充全文搜索；搜索和连接测试会消耗服务额度。
  没有可用 Key 时，可以尝试公开 HTML 搜索。

Key 保留在宿主设置中，不发送给模型。检索词、论文标题或 DOI 会发送给所用搜索服务。
连接测试成功不代表某篇论文一定可下载。

## 缺少 PDF 时怎么办

插件会尝试已有附件、来源链接、Zotero 解析器和仓库元数据。
支持时，也会用隔离浏览器读取公开页面。明确需要全文时，Agent 可继续检查已确认、
尚未更改的候选中获取失败的论文，并沿实际发现的链接寻找全文。

下载文件必须能解析为 PDF，并通过首页标题与 DOI 或作者核验。
补充材料、审稿文件和身份不符的论文会被拒绝。版本区分出版版、接受稿、预印本和未知；
PDF 中明确的版本声明优先于来源元数据。

仍无法获取时：

1. 点击**从浏览器获取**。
2. 使用你已有的访问权限下载。
3. 将 PDF 拖到卡片或列表中**对应论文的目标区**。

原文件不移动，通过核验的副本会附加到 Zotero。单个 PDF 上限 **100 MiB**；
扫描件或特殊首页可能需要在 Zotero 中人工核对。

## 限制与恢复

- 登录和人工验证码需在自己的浏览器完成，插件不读取浏览器登录 Cookie。
- 全文地址不能指向本机或内网；部分 VPN、代理 DNS 环境需要手动下载后拖入。
- 同时下载两篇，每篇获取约三分钟超时；失败条目可以单独重试。
- 每篇、每个确认版本的补充探索最多两次搜索、三个下载候选、十二步操作。
  搜索服务冷却在论文之间共享，反复换论文询问不会绕过冷却。
- 取消、更改候选或选择按当前结果继续后，不再发起新的补充获取。
  仅关闭工作区不会停止后台工作。
- 重启保留结果，把中断下载标记为可重试，不会自动重新执行研究。

## 研究子 Agent

主 Agent 可委派阅读或比较任务，最多同时运行三个。
点击子 Agent 的活动入口，可查看公开进度、工具和结论；关闭查看窗口不会停止任务。

子 Agent 只获得分配的来源和背景，不能代替用户审批、修改候选、写笔记或批注，
也不能再次委派。停止或删除父请求会取消关联工作。
子 Agent 的发现与主 Agent 直接读过的证据分别记录。
