# 知识库与记忆

[English](knowledge.md) · 简体中文

[使用指南](README.zh-CN.md)

## 查找研究资料

打开**知识库**，输入关键词并选择结果。
这里统一检索 Zotero 笔记、研究课题、偏好、普通记忆和旧知识库文件。

知识库只是索引，打开时读取实际来源。
笔记通过**在 Zotero 中打开**进行编辑，下次读取会使用新正文。
笔记或其父文献进入回收站后不再显示，恢复后重新可用；索引不会重新创建已删来源。

## 保存报告与导出文件

将[报告保存为 Zotero 笔记](reading-and-annotations.zh-CN.md)，以后保存会更新关联的同一笔记。
草稿和历史修订继续留在任务中。

**导出文件**生成独立 HTML 副本：

- 已写入笔记的报告版本，导出该笔记的当前正文。
- 未保存的版本，导出该版本的任务内容。
- 知识条目，导出当前读取的来源内容。

导出文件不会反向同步。公式、表格和来源链接会保留，图片与外部嵌入资源不打包。
旧知识库文件仍可原位阅读和导出，新报告不再生成这类副本。

## 记住研究课题

在**设置 → 记忆**中开启**自动维护普通记忆**。
普通对话成功结束后，Agent 可以保存明确表达的研究课题和偏好，
并更新同一课题的发现、待解决问题与下一步。

例如：“我正在比较小样本学习方法，请跨对话记住这个课题和待解决的问题。”

问过一次论文，不会直接视为长期兴趣。提取以你的原话为依据，但仍可能出错。
来源受限的预设和划线询问不会做这类跨课题提取。

维护使用当前模型及共用额度，在对话结束后执行，**不是定时监控或主动提醒**。
维护失败或被跳过不会删除对话和报告。关闭后停止新的自动提取与蒸馏，已有记录仍可查看。

## 纠正与忘记

选择记忆后，点击**纠正记忆**或**忘记**。
保存的人工纠正会受到保护，自动维护不会覆盖。
忘记会移除记忆，保留来源笔记和对话，并阻止迟到的自动工作重新创建规范化名称相同的课题。

抑制按名称匹配，不能保证拦截所有换名后的相似内容。
明确要求重新记住时，可以再次保存。
受保护记忆的修改需要逐项确认，普通工具授权不能替代。

## 保留与备份

普通记忆共用 **200 条、正文约 16k tokens** 的容量上限；90 天未被主动读取的普通
记录可能过期。活跃课题和受保护记录不按普通闲置期限淘汰，但仍计入容量；
容量不足时可能停止新增。

索引不是备份。需要保留哪些目录，请看[任务与数据](tasks-and-data.zh-CN.md)。
