## 连接 Codex 或 Kimi

1. 在运行 Zotero 的电脑上安装对应 CLI，并完成登录。
2. 打开 **Confucius 设置 → 运行时**。
3. 可执行文件路径留空，点击**重新检测**。
4. 核对检测到的路径与状态，再到输入区选择运行方式和模型。

自动检测覆盖 macOS、Windows、Linux 的常见 PATH、包管理器和桌面应用安装位置，
不要求 Zotero 自带 Node.js。

## 使用自定义安装位置

填写可执行程序的绝对路径。支持空格、中文、外层引号和 `~/`；
Windows 还支持 `%USERPROFILE%` 等常见路径变量。

- Windows Codex：可以选 npm 的 `.cmd` 入口，插件会解析到附带的原生程序。
- Windows Kimi：选择 `.exe`。
- macOS / Linux：选择原生程序或受支持的 Kimi Python 入口。
- Shell alias、仅安装在 WSL 内的 CLI 不能作为宿主程序使用。

手动路径无效时会报错，不会偷偷换用另一份安装。清空路径即可恢复自动检测。

## 常见问题

| 状态     | 处理方法                                                     |
| -------- | ------------------------------------------------------------ |
| 不可用   | 检查是否安装、路径是否存在及是否可执行；修复缺失的安装依赖。 |
| 需要登录 | 在 CLI 中完成登录，再重新检测。                              |
| 错误     | 核对路径、版本和错误信息，必要时更新 CLI。                   |

终端能找到、Zotero 找不到时，请填写完整路径：图形应用的 PATH 可能与终端不同。
版本检测成功也不代表账号有模型权限。其他问题见[常见问题](troubleshooting.zh-CN.md)。

自动化检测覆盖的安装方式多于实机验证范围；不能据此认为每个 CLI 版本都通过了真实任务测试。
