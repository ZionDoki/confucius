## 来源与对话

从 0.6.4-beta.3 起，新建对话会自动绑定 Zotero 阅读器中打开的 PDF。还没发送过
消息、尚未绑定的对话，也会带入随后打开的 PDF。当前 PDF 以简洁的 `@标题` 文字
引用预填在输入框开头。点击可按当前文库的文章标题或 PDF 文件名搜索、切换附件；
未绑定时可从 `+` 选择 PDF。

通过 `@` 选择的材料、对话会出现在光标位置。引用旁按退格/Delete，会整体删除该
引用并移除对应上下文。删除开头的 PDF 引用就解除绑定，即使该 PDF 仍然打开也不会
自动加回来。Cmd/Ctrl+Z 可撤销删除；切换对话或重启后，草稿仍保留引用身份和位置。
移除引用不会删除 Zotero 原始材料或历史消息。复制到输入框外的是普通文字，
不携带材料绑定。

切换阅读器标签或关闭 PDF 不会改变已有绑定。运行中需先停止回复再修改引用；
来源保存期间会等待保存完成再允许发送，普通正文仍可编辑。也可通过 Zotero 条目
入口、文件拖入或确认文献候选添加来源。0.6.4-beta.2 的新任务默认不绑定论文。

从 0.6.1-beta.1 起，PDF、Markdown 或 TXT 附件需拖入输入框的虚线框。
拖到周围工作区会显示提示，放到其他位置不会添加聊天附件。
补充调研论文的 PDF 时，请拖入文献审阅中对应论文的虚线目标区。

从 0.6.2 起，新发送的附件会在对应消息中显示文件名、大小和 PDF 页数，
切换任务或重启 Zotero 后仍保留。此前未保存附件元信息的旧消息保持原有显示。

侧栏提供**按时间**与**按文章**两种模式。
文章分组取决于对话的创建入口，之后添加材料不会把它复制到每篇论文下面。
从空白对话开始的检索归入文献调研。

关闭打开 Confucius 的 Zotero 文库主窗口时，独立工作区也会一起关闭。
任务与输入草稿会保存；关闭工作区不会停止正在运行的任务。
重新打开 Zotero 文库窗口，再点击 Confucius 工具栏按钮即可返回。

## 复制或编辑消息

从 0.6.4-beta.2 起提供。

在对话中选中文字后，按 **Ctrl+C**（Windows/Linux）或 **Cmd+C**（macOS）复制。
每条用户消息还有**复制**和**编辑消息**按钮，复制按钮只复制该条输入正文。
选中正在生成的回复时，这段文字会保持稳定，取消选择后显示最新内容。

编辑会在原消息位置打开输入框。**取消**或 **Escape** 保持历史不变，Enter 只换行。
点击**确认并重新发送**后，会替换该条消息、删除后面的全部对话，再带上保留的前文
执行修改后的请求。这项操作不能在聊天中撤销。运行中的任务需要先停止再编辑。
原附件会复用已保存的文本；如果文本已被清理，请新发一条消息并重新附加文件。

被截断的对话也会从任务历史检索中移除。已保存的笔记、批注、已接受的记忆和其他
聊天之外的修改不会回滚。如果编辑已保存但重新发送失败，修改后的内容会保留为草稿，
可以再次发送。

## 继续中断的任务

1. 重新打开任务，检查已保存报告和进度。
2. 点击**继续**，或发送继续请求。
3. 说明新增要求，重要引用和数字可要求 Agent 先核对再继续。

重启不会自动执行旧请求；继续会保留已经消耗的模型步骤和工具额度。
可恢复的网络错误会有限重试，鉴权错误、拒绝和用户取消不会按普通网络错误自动重试。

成功写入的内容保留。写入结果不确定时，先检查 Zotero 中的实际状态，或使用界面中的
状态核对功能，再决定是否重试。任务草稿无需文库写入授权；笔记等文库修改有各自
确认流程，批注建议始终需要审阅。

从某条回复建立分支，会复制该时点的独立报告和已保存研究状态。
两边后续改稿不会互相覆盖。

## 确认修改与目录访问

先核对目标和修改内容，再选**仅本次允许**、**本任务允许**或**拒绝**。
任务授权只覆盖该任务中对应的工具，不会自动接受批注建议或受保护记忆的修改。

任务默认**仅 Zotero**访问。需要外部运行方式执行命令或修改普通文件时，
先选中任务，再进入**设置 → 安全 → 指定工作目录**，填写并确认绝对路径。
命令和文件修改仍需审批；普通论文阅读无需开启此项。

## 数据存在哪里

| 内容                                     | 位置                                         |
| ---------------------------------------- | -------------------------------------------- |
| 任务、报告版本、历史、操作记录和批注归属 | 本机 Zotero profile：`confucius/runtime-v1/` |
| 研究记忆                                 | Zotero 数据目录：`confucius/memory/`         |
| 原生笔记、PDF 批注和附件                 | 由 Zotero 管理                               |
| 导出的 HTML                              | 导出时选择的位置                             |

设置中可查看实际运行数据路径。
**备份时保留 Zotero 文库、记忆目录和本机运行数据目录。**
只同步文库，不能在另一台电脑恢复完整的 Confucius 任务。

旧位置的运行数据可以迁移，源文件和恢复备份会保留至通过校验的清理阶段。
新版进度不会反向复制供降级使用。缺索引恢复只能利用本机仍存在的记录；
已删除或过期清理的历史不能凭空重建。

需长期保留的重要报告，请及时导出。另见[历史清理](context-system.zh-CN.md)
和[知识库导出](knowledge.zh-CN.md)。

## 排查问题

在任务的 **··· → 导出诊断报告** 中保存离线 HTML。
其中可查看已保存事件、报告版本并下载 JSON，不会调用模型。

已识别的凭据会脱敏，但研究正文和来源摘录仍会保留，分享前请检查。
已清理历史和外部运行方式未公开的内部数据无法重建。

云盘同步目录不能替代经验证的备份。先确认 PDF 已下载到本机；
完整多机同步、将数据库放入云盘等流程不属于已保证能力。其他问题见[常见问题](troubleshooting.zh-CN.md)。
