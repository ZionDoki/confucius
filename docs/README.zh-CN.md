# 使用指南

[English](README.md) · 简体中文

第一次使用，请先看[安装与第一个任务](../README.zh-CN.md)。准备 Zotero 和一个可用的
模型连接即可开始。

以下文档对应当前源码，已安装版本可能不同。找不到某个按钮时，先[检查已安装版本](updates.zh-CN.md)。

| 我想……                       | 阅读                                           |
| ---------------------------- | ---------------------------------------------- |
| 连接或切换模型               | [模型设置](model-selection.zh-CN.md)           |
| 解决 Codex / Kimi 检测问题   | [CLI 连接](runtime-discovery.zh-CN.md)         |
| 找论文、获取 PDF             | [文献检索](literature-research.zh-CN.md)       |
| 阅读、修改、保存报告或做批注 | [报告与批注](reading-and-annotations.zh-CN.md) |
| 选中文字后提问               | [划线询问](selection-questions.zh-CN.md)       |
| 查笔记、记住研究课题         | [知识库与记忆](knowledge.zh-CN.md)             |
| 继续任务、备份数据           | [任务与数据](tasks-and-data.zh-CN.md)          |
| 了解长对话和历史清理         | [上下文与历史](context-system.zh-CN.md)        |
| 安装更新或接收 Beta          | [更新](updates.zh-CN.md)                       |
| 处理错误                     | [常见问题](troubleshooting.zh-CN.md)           |

大多数设置都在工作区的**设置**中；Zotero 也提供 **Settings → Confucius** 入口。
先连接模型即可使用；OpenAlex 和 Tavily Key 是文献服务的可选配置。

参与开发请看[开发入门](../.github/maintainers/development.zh-CN.md)、
[界面规范](design.zh-CN.md)和[维护者指南](../.github/maintainers/README.zh-CN.md)。
