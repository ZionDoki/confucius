# 常见问题

[English](troubleshooting.md) · 简体中文

[使用指南](README.zh-CN.md)

先在设置中核对已安装版本。指南对应当前源码，旧版按钮和行为可能不同。

| 现象                                                                  | 处理方法                                                                                                |
| --------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------- |
| 模型没有回答                                                          | 核对所选运行方式、模型和端点凭据；CLI 状态见[连接说明](runtime-discovery.zh-CN.md)。                    |
| 模型或思考档位被拒绝                                                  | 核对账号权限、服务的精确模型 ID 和参数格式，见[模型设置](model-selection.zh-CN.md)。                    |
| 长任务停止                                                            | 检查已保存进度后继续，并补充重要约束，见[任务与数据](tasks-and-data.zh-CN.md)。                         |
| 论文没有 PDF                                                          | 可先用摘要或当前结果继续，也可在浏览器下载后拖到对应论文，见[文献检索](literature-research.zh-CN.md)。  |
| 拖入 PDF 被拒绝                                                       | 核对是否为目标论文正文、是否小于 100 MiB；扫描件或特殊元数据可能需在 Zotero 人工处理。                  |
| 知识库找不到笔记                                                      | 检查笔记及父文献是否在回收站；修改或恢复后重新搜索。                                                    |
| 保存要求知识库 ID，或提示“knowledge base or existing entry not found” | 这是旧保存路径。当前实现把报告保存为 Zotero 笔记，无需知识库 ID，见[知识库与记忆](knowledge.zh-CN.md)。 |
| 记忆没有更新                                                          | 检查自动记忆设置；维护可能被跳过、失败或额度用尽，对话仍会保留。                                        |
| 不确定批注是否已写入                                                  | 先“核对写入状态”并查看 PDF，再决定是否重试，见[报告与批注](reading-and-annotations.zh-CN.md)。          |
| 更新失败或显示旧版本                                                  | 按[更新排查](updates.zh-CN.md)处理。                                                                    |
| 移动数据后缺任务索引                                                  | 当前恢复只能利用本机仍有的历史和备份。不要手工伪造索引；旧运行目录缺失时需恢复完整备份。                |

## 收集诊断信息

在出问题的任务中选择 **··· → 导出诊断报告**。
反馈时提供插件版本、Zotero 版本、操作系统、所选运行方式、复现步骤和完整错误。

分享前检查导出的研究正文，不要包含 API Key 或配对令牌。
导出会处理已识别的凭据，但不保证移除所有私人研究内容。

可选 MCP 服务连接失败通常不会阻止工作区启动。
修改 MCP 配置后，重新启动插件再连接。
